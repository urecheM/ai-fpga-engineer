# Release v0.1.0 — Prototype (HDL generation)

# Initial release
**Date:** 2026-07-14

## Implemented features
- Config-driven architecture: models, prompts, benchmarks, synthesis,
  verification and optimization all structured YAML.
- Model providers: deterministic `reference` (upper bound), `synthetic`
  (fidelity-parameterised controls) and real `anthropic` (cached for repro).
- Benchmark suite v1: 18 benchmarks across arithmetic, FSM, communication,
  memory, processor, DSP and control, each with structured metadata, an
  objective difficulty score and a verified reference implementation. All 18
  reference designs analyze under GHDL `--std=08`. `comm_uart_tx` and
  `comm_spi_master` carry self-checking GHDL testbenches thru `testbench_path`/`testbench_entity`.
- Evaluation harness with identical procedure for every model
- Experiment registry (SQLite) with full provenance. JSONL logs.
- Category and difficulty breakdowns, auto-generated JSON/CSV/Markdown/HTML reports and SVG figures.
- `reproduce.py` regenerates every figure from the experiment registry

## Architectural changes
- Introduced the `hdleval` src-layout package with plugin registry, DAG
  orchestration, RAG retriever and self-repair diagnosis interfaces.
