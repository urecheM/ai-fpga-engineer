# Release v1.0.0 - Benchmarking

# Corrected release
**Date: ** 2026-11-12

## Fixes
- **Independent trials:** a per-trial `run_seed` replaces trials that were identical copies (effective n was 18, not 54).
- **Simulation on all 18 benchmarks:** golden-vector testbenches added for the 16 that had none. Skipped simulations count as `unverified`, not passed.
- **Semantic faults:** 7 fault types that compile, replacing syntax only faults. The static-vs-toolchain gap is now measured from the registry.
- **Measured Fmax:** nextpnr results on iCE40 UP5K replace the constant 100 MHz estimate. LUT/FF counts are populated.
- **Statistics:** exact McNemar tests and a paired bootstrap are now implemented.
- **Formal equivalence:** a SymbiYosys miter checks each candidate against the reference.
- **Toolchain enforcement:** `HDLEVAL_REQUIRE_TOOLS=1` now raises an error when a tool is missing. The Docker image sets it to 1.
- **Interface check:** entity name, port names, directions and widths are now verified. The entity declaration is included in the prompt.
- **Lint, not verification:** regex "properties" are reported but no longer decide pass/fail.
- **Failure sub-classes:** compile, synthesis and simulation errors are classified by tool message.

## Additions
- Parametric benchmark variants (`benchmarks/v1-variants/`, release seed 2026).
- Experiment `baseline-semantic-v1`, with equivalence checking enabled.

## Corrected results
- `baseline-v1` pass rates: 1.000 / 0.630 / 0.519 / 0.370 (previously 1.000 / 0.722 / 0.556 / 0.444).
- Static-only evaluation overstates correctness by 20–43 percentage points (McNemar p ≤ 0.001).
- Testbenches catch 219 of 240 semantic mutants; the miter catches 79 of 80.
